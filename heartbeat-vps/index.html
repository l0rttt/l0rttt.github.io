What this setup actually does
1 · Cron schedulerGitHub queues a scheduled workflow every five minutes. Starts can be delayed or missed during platform load.
2 · Temporary VMGitHub provisions an Ubuntu runner for the job. The runner is not a persistent machine.
3 · Job exitsWhen the job finishes, GitHub decommissions the hosted VM. The next cron pulse is a new VM.
Important: This is a cron-based compute/heartbeat demo, not a 24×7 VPS. It has no permanent process, stable server IP, inbound API endpoint, or durable local disk. It cannot host your Telegram bot/backend continuously.
